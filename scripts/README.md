# Scripts

Helper scripts for building, testing, and running experiments.

## Build Scripts

- `build.sh` - Build CUDA kernels and tests
- `clean.sh` - Clean build artifacts

## Validation Scripts

- `validate_experiment.py` - Check experiment output structure
- `compare_gpu_cpu.py` - Compare GPU vs CPU reference

## Utility Scripts

- `generate_config.py` - Create config from template
- `plot_results.py` - Visualize experiment outputs
