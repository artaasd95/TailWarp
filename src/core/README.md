# CUDA Kernels

Low-level CUDA kernels for high-performance computation.

## Modules

- `distributions/` - Heavy-tailed samplers (Student-t, α-stable)
- `manifolds/` - SPD manifold operations (exp/log, geodesics, projections)
- `risk_metrics/` - VaR, CVaR, tail estimators
- `utils/` - Common device functions (sorting, reduction)
