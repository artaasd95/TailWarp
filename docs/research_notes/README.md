# Research Notes (TailWarp)

This folder holds **human-readable research outputs**: summaries, experiment writeups, paper drafts, and lessons learned.

### Conventions

- **Keep each study self-contained**: include links to configs and experiment folders (or the command/script used to generate them).
- **Always include provenance**: git commit hash, hardware used, and the exact configs.
- **Prefer artifacts over raw data**: link to `quantiles.csv`, `histogram.csv`, `pot_fit.csv`, plots, and summary tables.

- See `INDEX.md` in this folder for a simple list of studies and notes.
