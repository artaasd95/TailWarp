# Risk Metrics

This folder holds the mathematical definitions and formal formulations of the
risk metrics we plan to implement in the project. Each metric should be
documented in its own Markdown file and include the math, key assumptions,
implementation notes, and a small example or test.

Typical sections for a metric file:

- Definition (math, use KaTeX for equations)
- Assumptions and properties
- Estimator / implementation notes
- References and a short example or test

Add one file per metric (for example, `cvar.md`) and link new files from this
README when ready.
