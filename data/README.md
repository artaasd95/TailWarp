# Data

Input and output data for experiments.

## Structure

- `input/` - Sample datasets (returns, prices, scenarios)
- `output/experiments/` - All experiment runs (timestamped folders)

## Experiment Naming

Format: `YYYY-MM-DDTHH-MM-SSZ__name__N{samples}__seed{seed}/`

Example: `2026-01-07T10-30-00Z__cvar_sizing__N10M__seed42/`
